# Libreria de JavaScript SELECTOR DE FECHAS 

Libreria de JavaScript inspirada en componente **`swing-datetime-picker` de Raven**. Desarrollada en **JavaScript Vanilla**, adaptada a y modificada para una version de JavaScript sin Frameworks.

## 🌟 Características Avanzadas Implementadas

1. **Navegación Rápida de Meses y Décadas (Años)**:
   - Al hacer clic en el encabezado central se conmuta entre la vista de **días**, la cuadrícula de **12 meses** y la cuadrícula de **décadas de años**, permitiendo saltar a cualquier año pasado o futuro al instante.
2. **Reloj Analógico Circular (Clock Face)**:
   - Esfera interactiva de reloj con manecilla direccional y puntero para selección visual de horas y minutos con un clic o arrastre (drag).
3. **Selección de Rango de Fechas (Date Range)**:
   - Habilita la selección de dos puntos (`startDate` y `endDate`) con resaltado visual del rango seleccionado y previsualización al pasar el mouse (hover).
4. **Reutilizable y Modular**:
   - Cada instancia es independiente y configurable mediante parámetros.
5. **Temas Claro y Oscuro**:
   - Soporte nativo para modo claro y oscuro (`light` / `dark`).
